=========================================
STEAM WORKSHOP UPLOAD GUIDE
=========================================

STEP 1: PREPARE YOUR MOD
-------------------------
Your mod is already structured correctly in the @ACE_Damage_Modifier folder.
The folder contains:
  - addons/ (contains the PBO files)
  - mod.cpp (mod configuration)
  - meta.cpp (Steam Workshop metadata)
  - README.txt (mod description)

STEP 2: CREATE PBO FILE
-------------------------
You need to convert the addon folder into a PBO file:

Option A - Using Arma 3 Tools (Recommended):
1. Install "Arma 3 Tools" from Steam
2. Open "Addon Builder"
3. Set source directory: @ACE_Damage_Modifier/addons/ace_damage_mod
4. Set destination: @ACE_Damage_Modifier/addons/
5. Click "Pack"
6. Delete the source folder (keep only the .pbo file)

Option B - Using PBO Manager:
1. Download PBO Manager (mikero's tools)
2. Right-click on @ACE_Damage_Modifier/addons/ace_damage_mod
3. Select "Pack into PBO"
4. Move the .pbo file to @ACE_Damage_Modifier/addons/
5. Delete the source folder

STEP 3: CREATE PREVIEW IMAGE
-----------------------------
Create a preview image for Steam Workshop:
- Recommended size: 512x512 pixels or larger
- Format: JPG or PNG
- Save as: @ACE_Damage_Modifier/preview.jpg

Suggestions for preview image:
- Screenshot from Arma 3 showing combat
- Text overlay with mod name and key features
- ACE Medical logo (if permitted)

STEP 4: UPLOAD TO STEAM WORKSHOP
----------------------------------
Using Arma 3 Launcher:

1. Open Arma 3 Launcher
2. Go to "MODS" tab
3. Click "OPEN WORKSHOP" button
4. Click "CREATE" to create a new mod
5. Fill in the details:
   - Title: ACE Damage Modifier
   - Description: Copy from README.txt
   - Tags: Select appropriate tags (ACE, Medical, Realism, etc.)
   - Visibility: Public (or your preference)
6. Click "Browse" and select your @ACE_Damage_Modifier folder
7. Select your preview image
8. Click "PUBLISH"

Using Publisher Tool (Advanced):

1. Open Arma 3 Tools from Steam
2. Launch "Publisher"
3. Create new item or update existing
4. Point to your @ACE_Damage_Modifier folder
5. Fill in metadata
6. Upload

STEP 5: POST-UPLOAD
--------------------
After successful upload:
1. The publishedid in meta.cpp will be auto-filled
2. Visit your mod's Workshop page
3. Add detailed description
4. Add screenshots if desired
5. Respond to user comments

UPDATING YOUR MOD:
------------------
To update after publishing:
1. Make changes to your source files
2. Re-pack the PBO (if you changed .sqf files)
3. Use the same upload process
4. Select "Update existing item"
5. Add changelog notes

IMPORTANT NOTES:
----------------
* Users must have ACE and CBA installed
* Add ACE and CBA as "Required Items" in Workshop settings
* Keep the publishedid value in meta.cpp - never delete it
* Test your mod locally before uploading
* Consider adding workshop tags: gameplay, realism, medical

TROUBLESHOOTING:
----------------
If upload fails:
- Check that PBO is properly packed
- Ensure meta.cpp exists and is properly formatted
- Verify you have a valid preview image
- Check your Steam Workshop terms agreement

If mod doesn't work after download:
- Ensure load order: CBA → ACE → ACE Damage Modifier
- Check RPT file for errors
- Verify PBO is properly signed (if required by server)

For more help, visit the Bohemia Interactive forums or mod's GitHub page.
